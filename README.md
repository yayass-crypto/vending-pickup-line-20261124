## The line

> Press my coin return — I've been saving your change since Tuesday.

A vending machine, speaking in the first person, offers the one thing it was
never supposed to keep: the passing human's change. The coin return is the
machine's own world; the punch — that it has been saving her change since
Tuesday — lands in the last few words.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (66 characters, 68 bytes, one line).
